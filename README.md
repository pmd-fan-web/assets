# 불가사의 던전 웹 — 에셋 (배경음악·도트 그림)

[불가사의 던전 웹](https://pmd-fan-web.github.io/)(비상업적 팬 게임)이 불러오는 배경음악과 도트 그림 파일입니다.
게임 코드는 [pmd-fan-web.github.io](https://github.com/pmd-fan-web/pmd-fan-web.github.io) 저장소에 따로 있습니다.

- `music/*.mp3`: Pokémon Mystery Dungeon: Explorers of Sky 사운드트랙.
- `sprites/items.png`, `sprites/traps.png`, `sprites/status.png`: Pokémon Mystery Dungeon: Red Rescue Team의 아이템·함정·상태 이상 그림.
  게임 저장소의 `tools/build_gfx.py`로 [The Spriters Resource](https://www.spriters-resource.com/)의 시트를 잘라 묶은 것입니다.
- 위 파일의 저작권은 Nintendo / Creatures Inc. / GAME FREAK inc. / Spike Chunsoft에 있으며, 이 저장소의 라이선스 대상이 아닙니다.
- 비상업적 팬 게임 용도로만 사용합니다. 권리자의 요청이 있으면 바로 내립니다.
  문의·삭제 요청: [GitHub Issues](https://github.com/pmd-fan-web/pmd-fan-web.github.io/issues)
- 이 저장소가 내려가도 게임은 자체 합성 배경음과 이모지 아이콘으로 계속 동작합니다.
