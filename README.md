# 불가사의 던전 웹 — 에셋 (배경음악)

[불가사의 던전 웹](https://pmd-fan-web.github.io/)(비상업적 팬 게임)이 불러오는 배경음악 파일입니다.
게임 코드는 [pmd-fan-web.github.io](https://github.com/pmd-fan-web/pmd-fan-web.github.io) 저장소에 따로 있습니다.

- `music/*.mp3`: Pokémon Mystery Dungeon: Explorers of Sky 사운드트랙.
  저작권은 Nintendo / Creatures Inc. / GAME FREAK inc. / Spike Chunsoft에 있으며, 이 저장소의 라이선스 대상이 아닙니다.
- 비상업적 팬 게임 용도로만 사용합니다. 권리자의 요청이 있으면 바로 내립니다.
  문의·삭제 요청: [GitHub Issues](https://github.com/pmd-fan-web/pmd-fan-web.github.io/issues)
- 이 저장소가 내려가도 게임은 자체 합성 배경음으로 계속 동작합니다.
